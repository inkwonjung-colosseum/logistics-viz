# 학습 패턴 표준 (Learning Pattern)

모든 개념 페이지가 따르는 공통 구조. "보여주는 사전"이 아니라
**만지면서 배우는 시뮬레이터**를 만드는 것이 목표다.
토큰·접근성 규칙은 `design-tokens.md`를 우선 따른다.

## 페이지 5단계 구조

| # | 단계 | 규칙 |
|---|------|------|
| 1 | **정의** | `h1` + 한 줄 정의 (개념어는 굵게, 비유 하나 허용) |
| 2 | **체험** | 시뮬레이션 — 재생/일시정지/초기화 컨트롤 필수 |
| 3 | **손잡이** | 파라미터 2~3개 (모드 토글·슬라이더). 값을 바꾸면 결과가 **즉시** 갱신 |
| 4 | **숫자** | KPI 3개 이하. `tabular-nums`. 승자/패자를 이름으로 말해준다 |
| 5 | **결론** | 한 줄 takeaway. "그래서 실무에서 ~한 이유"로 끝낸다 |

## 콘텐츠 원칙

- **대결 구조**: 개념은 혼자 설명하지 않는다. 나란히 두거나 경쟁시킨다
  (FIFO vs LIFO vs FEFO, 직송 vs 허브, EA 스캔 vs LPN 스캔).
- **결정론적 시뮬레이션**: 시드를 고정해 조건이 같으면 항상 같은 결과.
  비교 공정성(모든 정책이 같은 수요·같은 입고를 만나는지)이 1순위.
- **손잡이는 트레이드오프를 드러낸다**: 파라미터를 극단으로 움직이면
  순위가 뒤집히거나 격차가 벌어져야 한다. 항상 한쪽만 이기는 손잡이는 죽은 손잡이.
- **전제는 밝힌다**: 단순화한 가정(후처리 비용, 차량 적재율 등)은
  각주나 캡션으로 한 줄 명시.

## 진도 (완료 버튼)

- 모든 페이지 하단에 `✓ 학습 완료` 버튼.
- 클릭 시 `localStorage['mv-done:<slug>'] = '1'` 저장.
- 홈(`index.html`)은 같은 키를 읽어 카드에 ✓ 배지, 트랙 진도 바를 그린다.

## 페이지 공통 골격

```
┌ 뒤로가기(← 카탈로그) ─ 카테고리 · h1 · 한 줄 정의
│ [시뮬레이션 패널: SVG, role="img" + aria-label]
│ [컨트롤: 모드 토글 | 슬라이더 | 재생/초기화] (한 행, aria-live 상태줄)
│ [KPI 카드 ≤3]
│ [takeaway 한 줄]
└ [✓ 학습 완료]
```
